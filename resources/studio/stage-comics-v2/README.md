# Bloma 五阶段三格小漫画

2026-10-26。使用内置 `image_gen` 生成，统一沿用用户认可的“发现异常 → 追赶 bug → 抓住它”三格漫画风格：淡彩线稿、同一成年角色、镜头变化及小反转。

本组已按用户指令接入正式工作区顶部阶段条。悬停/聚焦显示对应漫画，点击可以固定和放大。完整图保留供精修；`*.thumb.webp` 为运行时使用的 1086×362 缩略图。
