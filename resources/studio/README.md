# 星屿画室角色素材

这些素材由内置 `image_gen.imagegen` 生成，经用户确认后用于 Bloma UI。这里均为原创角色；东方 Project 同人插画气质与 fumo 布偶形态作为视觉参考。图像以 WebP 存储，保留原始 alpha 透明通道，没有使用 CSS 绘制人物替身。

| 文件 | 用途 |
| --- | --- |
| `guide-neutral.webp` | 首页默认成年立绘，放空神情 |
| `guide-wave.webp` | 单次点击后的轻微歪头、抬手回应 |
| `guide-blush.webp` | 连续点击后的脸红与举拳头姿态 |
| `guide-fumo.webp` | 侧栏、聊天头像、空状态的静态布偶；不增加点击动作 |

## 最终提示词要点

- 默认立绘：明确为约 27 岁成年女性，六头半至七头身、正常成年面部，银紫肩长发、半睁眼、放松站姿；小象牙白软帽、薄荷蝴蝶结与叶片、长袖衬衣、淡紫中长裙。参考传统东方同人插画的轻手绘线条和平涂；避免大头、娃娃脸、幼态姿势。透明背景，全身可见。
- 回应姿态：以上默认立绘作为编辑目标，保留成年比例、身份、服装、画风、尺寸、脚部位置与透明画布；只修改头部、表情和画面左侧手臂。头微歪约 7 度，半睁眼、轻微笑意，抬起开放手掌轻轻回应。避免夸张活泼或幼态表现。
- 脸红举拳：同一默认立绘作为编辑目标，保留上述身份与构图。两颊轻微泛红，眉毛稍收紧、嘴微抿，画面左侧手臂弯曲，将小拳头抬到肩/脸侧，表现被反复戳后的佯怒。不是攻击动作，不放大头眼、不改变成年比例。
- 布偶：以上成年立绘作为身份与服装参考，生成实物缝制布偶形态。圆布头、淡色绒布脸、刺绣半睁紫眼、极简小嘴、小躯干、短手臂、正面坐姿，双脚朝前；可见柔和布料与接缝，保留银紫毛发、薄荷叶与蝴蝶结、象牙白帽和淡紫裙。透明背景，整体完整。

原始生成文件保存在本次会话的 Codex generated_images 目录；程序消费本目录的版本化文件。布偶形态参考入口：[Gift 东方布偶](https://www.gift-gift.jp/nui/nui139.html)。这是 UI 绘图素材，不是官方商品照片。
