# 贴图提需求（视觉输入）说明

> 2026-10-06 体验批 D。目标：用户粘贴界面截图 + 一句话（如「照这个做一个」）即可提需求。

## 现状

- **管道已通**：ChatPanel 粘贴图 → `pasted-image:save` → 消息携带 image block（`loop-query` 已过滤合法 refs）→ LLM 请求。零代码改动。
- **提示词已教育**：向导系统提示词（内置 `guide-runtime.ts` DEFAULT + 外置 `~/.proma/prompts/guide-system.md`，双写纪律）已加【用户贴图时】段——要求先归纳图中界面再结合文字理解；**渠道无视觉时如实告知，严禁虚构图片理解**（防幻觉关键）。

## 视觉渠道配置

文本模型渠道（如 glm-5.3 / deepseek-v4 / kimi-k3）**不能读图**。需要读图时在设置 → 模型渠道里配置一个视觉模型渠道，例如：

- 智谱：GLM-4V 系列（open.bigmodel.cn，anthropic-compatible 同端点）
- 月之暗面：Kimi 视觉版模型

配置后把该渠道用于向导对话即可。视觉渠道未配置时贴图不会报错——向导会如实说明看不到图，请用户文字描述（提示词纪律）。

## 验收路径（真机）

1. 配置视觉渠道并切换向导对话使用它
2. 粘贴一张软件界面截图 + 输入「照这个界面做一个桌面版」
3. 预期：澄清问题/PRD 中体现对图中界面结构的理解（布局/控件级描述）
4. 反例（无视觉渠道）：贴图后向导应回答「未能读取图片内容」而非编造
