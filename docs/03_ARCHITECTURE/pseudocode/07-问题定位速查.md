# 07 — 问题定位速查（症状 → 可疑函数 → 检查点）

> 从故障现象倒查代码。每行给出：**症状** → 最可能涉及的函数（锚点）→ **检查点**（看什么 / 怎么确认）。
> 配套：`01-用户旅程与编排.md`（主链路）、`04-渠道与存储.md`（渠道解析链）、`05-IPC与渲染层.md`（事件流）。

## 通用定位工作流

1. **先确认权威阶段**：`findProject(project_id).current_stage`（渲染端可能滞后）。
2. **看决策日志**：`~/.proma/` 下 `decisions.md` 的 `recordDecision` 条目（渠道切换 / 澄清 / 审查 / 修改门都有留痕）。
3. **看会话 JSONL**：`~/.proma/` sessions 目录，`[decision-card]` 内部标记记录弹过哪些选项。
4. **看埋点**：`sketch_fallback` / `sketch_generated` / `mvp_delivered` / `agent_loop_turn`（含 duration_ms / llm_attempts）。
5. **看事件流**：临时打开 DevTools 或加日志，确认 `stage_changed` / `user_decision_required` / `delegation_*` 是否到达渲染端。
6. **跑对应测试**：`npm run test:unit` 定位到 `tests/unit/<模块>.test.ts`，失败用例即复现路径。
