2026-10-26。起点 `sprint2 / fa6659c`。用户已授权将预案落实到正式 UI；本批修改 renderer、显示偏好和界面素材，未修改执行器、确认协议或交付门禁。

## 当前行为

- 左侧预览、最右侧会话，右栏首次默认 300px，可拖动、键盘调整和双击恢复；已有宽度偏好保留。宽度不足时切换对话/预览视图。工作区保持实际窗口高度，输入不会随历史消息被挤出窗口。
- 人物融入最新一条真实助手发言，需求姿态按同一回复的稳定标记选择；打字和缩放不会随机换图。可以收起人物并记住偏好。没有用演示台词替代模型输出，完整历史、复制、从消息新开讨论、附件、语音和原发送入口保留。
- 五个顶部细线阶段为需求、界面、制作、验证、交付。绿表示阶段已结束，蓝表示当前阶段，白表示待开始，红表示需要处理。暂停也属于需要处理，详情明确说明原因，不能误写成验证失败。
- 蓝线仅在实际运行时流动；等待确认时保持静止，系统减少动态效果偏好关闭流动。阶段由项目/会话状态投影，时间不会自动推动进程。
- 悬停、键盘聚焦或点击可打开阶段详情，显示各自三格漫画或实际进展摘要。支持移入弹层、点击固定、放大漫画、Escape 关闭和工作记录入口；这些查看操作不发送模型请求或触发阶段推进。
- 没有确认草图证据的直通/导入路径不会显示界面已通过；未知阶段不显示绿色完成；待确认的旧项目不会仅因之前交付而跳过新确认。阶段颜色是导航呈现，不替代宿主验收结果。
- 专注预览保留原 iframe 和输入草稿。完整画布、适应窗口、原尺寸、缩放与标记模式沿用现有 SketchViewport；草图与程序身份仍使用实际预览/交付面板。
- 保持浅色，使用灰白底板、白色作品表面、右侧对话面和局部淡紫发言建立层次。主操作移到会话输入之前；需求、UX 和续跑均继续调用原处理函数。
- 等待提示移除无条件的“不会影响电脑文件”和仅凭时长断言“我还在处理”；进度卡改用已结束阶段数，避免将阶段百分比误认为总工作量。

## 接线

`WorkspaceShell` 组织顶栏、阶段条、作品、资料和右侧会话。`WorkspaceHeader` 的 compact 变体保留主页面、项目、模式升级、设置入口。`ChatPanel.actionSlot` 容纳实际确认与续跑操作；`ReplyCharacter` 装饰实际发言，消息正文和业务身份保持原样。

`workspace-progress.ts` 为纯状态投影；`WorkspaceProgress` 负责只读弹层。`workspace.css` 仅覆盖工作区，不重做主页、项目管理或设置业务。新桌面断点覆盖了旧 1099px 查询，避免 1024px 下预览被旧规则隐藏。

本地上游参考版本 `proma-upstream / bf3e98c`：`AppShell.tsx`、`right-panel-layout.ts` 的左右区域与宽度边界，`ChatInput.tsx` 的独立草稿/发送组织，`ui/popover.tsx` 的 portal 和弹层层级。适配到本仓 React/Jotai 与现有输入/确认链，没有引入 Radix、TipTap 或新动画依赖。
