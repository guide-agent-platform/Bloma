# 画布适配与界面动态修复

日期：2026-10-13。实施基线 `40035d3`，本批仅修复 UI，不继续模型对照实验或启动生成任务。

## 问题与结果

原来的「适应画布」只使用宽度，忽略画布高度；iframe 固定为 1280×800，长草图下方内容仍需要滚轮才能看到。现在使用画布可用宽高与草图完整尺寸的较小比例，四周留 12px，整页居中显示。长页面适配时可低于 10%，不再用最低缩放比例阻止完整显示；新增放大、缩小按钮，保留原尺寸与专注预览。

本地 HTML 预览协议通过 `bloma-viewport=1` 显式请求尺寸桥，仅在响应中加入只读测量脚本，不回写草图文件。草图仍从原 URL 加载相对资源，doctype 保留；确认后回看继续使用不带同源权限的沙箱。父页面核对 iframe 来源、当前页面 token 和有限的数值范围，再接受尺寸。初次加载、图片/字体加载、内容与样式变化触发重测，变长和变短均可重新适配。按原尺寸查看时允许画布滚动；草图自身的可滚动列表与应用内部交互仍保留。

缩放、专注切换不重新挂载 iframe，保留页面内输入和点击状态。切换另一草图时重置尺寸与缩放。兼容点选纠错原尺寸模式，模式开启期间禁用缩放按钮并保持原设计视口。外部 HTTP 页面没有本地测量桥，仍按基础设计视口适配；本批真实内容尺寸验证针对平台本地草图。

## Hover 与过渡

图标增加轻微抬升/放大，预览工具图标增加轻微旋转；导航、设置标签和专注按钮统一颜色、背景、按下反馈。工作区、项目列表、想法页与设置页增加短暂淡入；资料面板从右侧进入，设置标签与阶段标题切换时轻微淡入，专注预览切换只使用透明度反馈。没有为动效重新挂载草图或聊天输入。

按钮反馈参考本地 Proma `bf3e98c` 的 `apps/electron/src/renderer/components/ui/button.tsx`（150ms 颜色/阴影过渡和 active scale 0.97），适配为现有 CSS 和 Lucide 图标，未引入 Radix/Tailwind 或新的动画库。系统减少动态效果偏好关闭这些动画与过渡。
