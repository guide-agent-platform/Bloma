# 软件 Agent 工程底座改造

2026-10-24，用户授权深度改造并自主完成必要工程与验证。起点 `sprint2 / 0bfa41e`。原有 `production-workflow-v2-20261020.md` 两行用户改动不纳入提交。不推送、不重启用户实例、不运行付费生成或改写冻结实验。

## 产品与实施决定

定位：能自主选用成熟软件技术、持续运行调试并交付可使用软件的 Agent，用户只决定用途、数据与外部影响。平台宿主继续 Electron，执行循环继续 Pi 与现有渠道/账本；不把接入某家模型当成软件能力改造。

新项目使用 `software-v1` 语义，复用已经精简的目标/草图/制作/验证链。`lean-v1`、无版本历史项目和冻结实验仍按原约定读取和运行。新版本不强制 Python 骨架，不禁止 npm 构建；前端优先成熟生态，具体框架由任务与已有工程决定。

采用一个连续主负责人。独立调研、只读审查、明确文件所有权的实现任务才委派；短任务、接口未定任务、同一共享状态的改动留在主负责人。子任务继承总预算、取消和同一目标，结果不是交付通过。默认不跨模型、不嵌套分派、不恢复 AC 角色流水线。写入所有权由宿主约束，不能只靠提示词协调；主负责人负责集成与最终真实验证。

## 取舍与安全边界

通用终端是工程能力，不是 OS 沙箱。项目路径检查、环境清洗和命令参数校验不等同系统隔离；新增执行接口如实说明边界。保留权限层、密钥外置、总请求/输出/时长/费用控制、进程所有权和取消。正常项目依赖与构建自动进行；系统级安装、外发、付费、破坏性真实数据操作仍使用授权边界。所有验证使用隔离数据，不把进程存活、脚本自报或工具执行成功当作功能完成。

先把 Windows 的 Node/JavaScript/TypeScript、Python 与 Electron/浏览器做成真实可用路径；没有真实观察器的平台如实未支持，不能靠声明增加“全栈支持”。不自动引入云部署、移动构建、系统容器安装或新的供应商费用。

## 来源与适配

- 此前两份学习软件的现存工程表明 Electron 与成熟 JS 库可以承接真实文档与界面需求；不把两个不同模型样本视为受控质量实验。

## 最终协作安排

| 工作 | 默认安排 | 宿主约束 |
| --- | --- | --- |
| 需求落地、接口未定、UI与业务集成 | 连续主Agent完成 | 相同会话与执行现场，不重开流水线 |
| 独立查资料、定位入口、只读审查 | 可并行子任务 | 只读工具；源码变化后结果标为旧参考 |
| 明确文件边界的实现 | 必要时并行 | 显式write_paths，重叠拒绝；主Agent不覆盖活跃子任务文件 |
| 任意命令、依赖、服务、构建、验收 | 主Agent集成后运行 | 等写入者收口；共享目录子Agent没有任意命令权限 |
| 最终功能验证 | 宿主观察正常程序 | 子任务结束、自报通过、HTTP存活都不替代业务断言 |

默认最多2个子任务并行、单层、同渠道同模型，所有模型请求和重试共用既有账本/请求/输出/时限，不增加子Agent专属额度。取消先撤销文件权限，再等实际循环退出；进程服务使用父管道监督，宿主消失会回收其服务后代。用户主动启动的成品实例单独归属，不随Agent会话停止。主Agent最后统一集成、检查、交付。

实现中曾添加“32次工程命令”和“4次派发/续接”两条固定限次，最终删除：它们重复已有总预算，会截断正常构建修复。保留并发、文件归属、共享预算和无进展约束，不再叠加一套角色流水线或限次表。未默认跨模型路由，避免在没有受控证据时把不同模型质量差异算成harness收益。

截图默认保存到本机，inspect_app默认只返回DOM观察与位置；已知渠道支持图片时才显式附图或view_image。未知/纯文本渠道不自动收到截图，不另起付费视觉审查。Pi原生会话和审计只存图片短引用，原有传输边界负责水合。

## 已知边界与后续优先级

1. 新项目开始使用；历史项目不自动迁移、清额度或重跑。当前运行中的用户Bloma未被重启，也未向远端推送。
2. Electron点选已实现；浏览器点选、上传/原生文件对话框与其它专门能力观察器仍需按实际任务扩展。未知观察不能放行成PASS；ASR等原有Python能力适配保留。
3. npm CLI已提供；当前机器上的Node/Electron/浏览器和Python实际验证不等于在无任何开发环境的新机器上完成安装包验收。发行版运行时、离线依赖与真正独立打包需要单独环境验证。
4. 用户数据独立于测试/源码，版本变化前备份；已运行旧实例须用户明确选择重启更新。备份目前留在项目专属数据目录，未增加完整恢复管理界面；运行服务仍读现有源目录，不宣称具备不可变发布快照。
5. 泛用命令不是OS沙箱。共享工作目录写入权限仅由文件工具强制，任意命令因此保留在主负责人；需要子Agent也能任意执行时，应先实现真正隔离的工作树/运行环境与集成，而不是继续加提示词。
