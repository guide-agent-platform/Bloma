## 交付与接线

B0 在 `main/software/component-contracts.ts` 给 AI、HTTP、文档及产品设置提供同一描述结构：ID/契约版本、组件版本、源文件 SHA-256 与整体摘要、公开配置 schema、适用运行时/依赖、接口、错误/取消/副作用、验证入口和限制。既有 `inspect_software_capabilities` 返回 contract，components topic 返回同源目录；没有重建插件系统。版本是描述版本，源码是否相同须核对摘要；旧产物不会自动迁移或覆盖。

准备沿用原入口，保护已有公开路由及用户代码。文件摘要对平台源与产品配置分别表达；发现代码冲突时保留原字节并拒绝，不做隐式升级。AI/HTTP/文档各自保持原运行探针及依赖策略；准备完成不表示完整产品 UI 或业务已通过。文档接口本身不接收有效的取消信号，契约明确解析须放受监管进程；不能把额外传入的 signal 当作已实现中断。

B1 新增 `main/templates/components/product-settings/`，物化时沿既有平铺路径落入产品工程。入口：

```js
prepare_software_capability({capability:"product-settings"})
inspect_software_capabilities({capability:"product-settings"})
```

准备不安装 Electron、不发网络请求。可在产品自身具备 Electron 39 的 Node 工程中运行：

```powershell
# APP_DATA_DIR 必须为该产品自己的数据目录
npx --no-install electron product_settings_electron.cjs
```

此命令用于已准备的产品工程，不能在 Bloma 仓库根直接寻找同名文件。后台 `createProductSettings({dataDir,safeStorage})` 与 UI `mountProductSettings(root,bridge)` 可组合使用；独立 HTML/Electron 窗口只是最小可运行适配，样式/布局应服从用户已确认设计。产品须使用自己的 Electron 与数据目录，不依赖 Bloma IPC、源码绝对路径或渠道 Key。普通 Node backend 准备成功不认证 Electron 是否已安装或完整 GUI 已加载。

表单支持既有公开路由的选择、默认路由、两种协议、API 基地址、模型、网络范围、超时、输出 token 参数及遮罩 Key 输入。路由集合由公开模板定义，本批不增加界面创建/删除路由；HTTP/Webhook 专用字段、OAuth、分页及同步状态归 B4a/T03。T01 因此记为 AI 首期适配完成，连接器设置仍部分待办。

## 状态和密钥边界

- renderer 仅可调用 `read/save/check/cancel`；无任意 IPC、任意模型请求或 secret getter。后台 `ai` 供产品业务使用，不能整体暴露给 renderer。Electron 样例检查窗口、主 frame 和固定文件 URL，关闭导航/新窗口，并使用隔离和 sandbox。
- 公开配置与 Key 分开。使用本产品 `safeStorage`，加密不可用或 `basic_text` 时拒绝 Key 持久化，没有明文降级。空 Key 输入保留原 Key，取消丢弃草稿。尚无 Key 删除 UI。
- 保存先验证公开 schema 和 revision，再以新的独立密钥 ID 写入密文，最后 CAS 提交路由；公开提交失败会移除本次暂存密钥，旧路由/旧 Key 保持不变。中途进程崩溃可留下未引用密文，但不会提前替换旧配置；本批保留旧未引用密文，不提供自动清理或密钥备份恢复功能。
- 保存不联网、不发模型请求。显式勾选可能计费同意后，检查向已保存路由发一条短请求；不会自动重试。结果只认证该次响应可解析，不返回模型原文，不证明供应商理解能力或业务效果。
- 配置保存使连接状态失效并取消旧检查；陈旧表单拒绝。取消只能中断客户端等待，已发送的供应商请求可能仍产生费用；不能据此撤销外部计费。首次/重开后的连接状态重新检查。

参考本地上游 `proma-upstream / bf3e98c` 的 `channel-manager.ts` safeStorage 边界及现有产品 `ai_secrets.cjs`；上游明文回退没有采用。没有整体移植平台渠道管理或渠道数据。

1. 后台测试把“无密钥落盘”误写成“无空目录创建”，修正为检查没有密文文件；没有把空目录当密钥泄漏。

4. 新增工具接线用例漏传 `createProject.mode`，单测执行可过但类型检查拒绝；补齐输入，`types-initial-failure.log` 保留，最终重新检查。

另有源文件完整可见界面检查：修正了保存消息持续显示“尚未检查连接”而可能与后续连接结果冲突的问题。公开配置已保存、Key 可用与连接结果分别显示；检查未产生真实质量或提速结论。
