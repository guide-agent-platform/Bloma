# Bloma 视觉深化：通透画室 / 静白聚光

日期：2026-10-11。用户认为上一份修改稿仍像普通工作台，要求进一步体现Apple UI的视觉质感。本轮只制作两套独立视觉预案；没有修改应用源码、构建、打包、启动或重启Bloma，也没有操作用户正在测试的实例。

本稿承接 [功能与布局修改稿](ui-revision-20261011.md)，其中简短中文正文、内部消息来源隔离、复制/重开真实反馈与语义、旧组件逐项改造要求继续有效。本次主要深化视觉与布局气质，不宣称这些功能已经修复。

## 参考与适配

参考Apple官方 [Build an AppKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/310/) 的可读文字：工具与导航浮在内容之上、相关控件分组、信息文字不伪装按钮、边栏与内容形成不同层次、容器与内部控件圆角有协调关系。

[Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 页面正文抓取要求JavaScript，本轮不声称阅读了该页全部细则。实际依据是上述WWDC文字，以及已知Apple界面的视觉组织。

本预案是Windows/Electron可适配的HTML/CSS视觉演示，不是Apple原生Liquid Glass实现，不包含原生折射API、AppKit材质或SF字体的分发。Windows使用系统字体和微软雅黑UI回退，线稿图标仍使用Lucide；保留Windows窗口操作，不伪造macOS交通灯或Apple标志。

## 方案：通透画室（优先探索）

- 带轻微暖/绿背景光的整块工作区；窄项目边栏与悬浮工具呈轻通透材质。
- 程序预览是清楚、不透明、边界精细的独立纸面，占据主要空间。玻璃不叠到方案正文上，保留阅读对比。
- 左侧整合项目、阶段与资料入口，不再增加两层横向进度栏。选中阶段像一块轻轻抬起的小平面，不用强烈色块。
- 短回复与输入组成下方薄讨论带。正常文字完整显示，不截断、不折叠。历史在独立面板回看。
- 一组胶囊工具、单个主确认动作、细致阴影和协调圆角形成层次。动作反馈约160ms，支持减少动态；不使用循环闪光和持续漂浮。
- 专注预览时同时收起边栏和讨论，把完整画布留给复杂草图。

## 方案：静白聚光

- 更沉静的白色桌面编辑器方向；边界弱化，内容本身成为焦点。
- 阶段为紧凑的分段导航，项目资料在顶栏；右侧讨论长期可见，适合持续讨论。
- 主操作使用更深、收敛的颜色，影子和背景光更少。草图保持清楚的独立平面。
- 与通透画室在导航位置、讨论组织、专注行为、材质和空间关系上都不同，不是只换颜色。

两套均保留绿色长期型/紫色快速型。主题只影响平台导航与主要动作，不重新染色用户生成软件。默认浅色，与用户当前浅色要求一致。

## 原型范围与检查

独立源：本聊天可视化目录 `bloma-apple-directions.html`，包含可切换的两套完整预案。状态控制可切换草图/制作暂停/试用，支持专注预览、项目资料、讨论历史和短回复交互。

所有发送、启动、复制、分支、文件与语音操作仅作演示；不会触发真实模型、真实项目、系统剪贴板或程序。原生草图视口缩放、标记坐标转换仍需实施阶段接线，本原型只演示画布空间关系。

独立无头浏览器检查：两套视图的专注预览实际扩大画布；文档/版本/历史可打开；制作/试用主操作随状态改变；1024/736/520/320px无横向溢出，可见控件不超出边界；线稿图标正常，页面异常0。证据 `apple-direction-checks.json`、`apple-glass.png`、`apple-white.png`；脚本 `run-artifacts/check-apple-directions.mjs`。

完整渲染预案与真实Electron运行是不同证据。本次没有typecheck/build或平台运行验收，因为没有修改应用源码。只有用户认可方向后才进入具体组件实施；原先的功能缺陷不能靠视觉预案视为已解决。
