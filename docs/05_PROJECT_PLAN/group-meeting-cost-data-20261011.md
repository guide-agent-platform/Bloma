# 组会测试结果与成本数字底稿

日期：2026-10-11。配合[发言稿](group-meeting-script-20261011.md)，本文保存已放进发言稿的数值及统计口径。当前纳入 11 个命名已交付项目：主 home 10 个、隔离 home 附件账本 1 个；这是历史案例集合，不是统一难度的随机实验样本。

## 统一口径

- 时间为该项目全部 `desktop_dispatch_run.duration_ms` 之和，称“开发阶段累计时长”；包含阶段内的子任务等待/执行，不再额外叠加子会话墙钟时间。没有把用户等待、澄清、测试前后准备或独立 GUI 验收全计入，所以不是端到端 Time-to-MVP。
- token 为阶段主会话 `usage.input + usage.output` 的记录值，含该项目已记录的重跑与续验。不是包含所有子 Agent、需求阶段和辅助调用的完整账单。
- `est_total` 在源码中还加入交接/宽限辅助调用的估算；不能混同输入/输出报告值。这里将两列分开。
- 使用原始 event_id 去重；同一 run 的 latest/result 副本不重复计数。父会话记录与子会话 transcript 工具数量分别使用，不将工具次数当作模型轮次或测试数。
- 缺少模型价格、缓存计费和完整子会话用量，本文报告时间与 token，不换算人民币。

- 共 11 个案例、40 个阶段运行段、1010 个主轮次。

## 原始来源与时间终点

- 本机机器汇总：`run-artifacts/test-case-cost-inventory.json`；读取脚本 `aggregate-case-costs.mjs`，数据来自真实/隔离 home 的 projects、analytics 和会话索引。
- token 口径源码：`main/desktop/dispatcher-telemetry.ts` 的 usage；`main/agent/loop/agent-loop.ts` 的 attachUsage 与辅助调用估算。子会话当前没有在这些阶段主会话字段中完整汇总，原始会话终态也主要保存总结，不宜凭空补齐费用。
- 贪吃蛇、扫雷、教务等较早样例没有找到 desktop_delivery_outcome 事件，但有项目 completed 状态和阶段运行；表中未用“更新时间”假冒端到端终点。
