# 长期型里程碑与持续维护（批次 C）

长期型 software-v1 现在以已确认范围为里程碑：制作和宿主验收完成后封存候选，先供试用；用户确认当前阶段后，重新检查同一候选再发布。快速型保持验收后交付。两者仍共用预算、能力验证、回归基线、数据快照和发布隔离。

## 持久记录与交互

- 独立保存里程碑、候选版本历史、待办和关键决策；项目索引只保留显示摘要。文件有校验和、修订号和容量上限；损坏、旧修订、跨会话或范围变化均拒绝执行。
- 待确认候选只封存，不替换当前可用版本。阶段试用执行封存的同一版本，使用试用数据；命令型试用显示实际退出输出。宿主检查通过不等于独立机器认证。
- 确认绑定范围、执行轮次、源码摘要和候选身份。发布前重验原候选；先持久保存确认意图，再切发布指针。中断后保留待核对状态，需要新的明确确认，不自动发布。
- 待办不会自动实施。选择待办先合并原功能、约束与范围外事项，生成下一轮任务单，仍需确认范围。正在制作时只记下采用意愿；归档项目不能开工。
- 查看记录、恢复待确认卡、稍后核对和确认阶段本身均不启动编码模型。明确修改才回到制作；“继续”不能把已交付阶段理解成无限自动迭代。
- 制作工具可记录带理由的关键决策。面板显示阶段、历史、待办和归档操作；完成阶段与整个长期项目归档分别表达。
