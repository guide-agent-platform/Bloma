## 当前接线

`lean-production.ts` 在界面候选的 C 审阅完成后检查 V；缺少当前 V 时实际启动同模型的独立只读 review 子会话。无界面任务只走 C。新源码、确认目标/设计或环境绑定使旧审阅失效；同一候选分别需要最新的完成 C 和 V，不能用两者互相替代。重要已确认 finding 仍须在当前候选复测关闭。

V 继续沿现有 Pi、委派生命周期、最多两并发、父渠道/模型、共享请求/输出/金额预算。当前自动接线顺序为 C 后 V，并未为并行增加另一套执行引擎。没有新增模型选择面板、跨渠道权限或经理 Agent。

宿主采图使用现有 debug observer：复用父会话当前 ready 实例，或沿正常 LAUNCH 入口打开，实际观察后采集 PNG、DOM、操作结果及受界限的日志事实；检查观察前后源码和完整候选身份一致，再关闭开发实例、冻结受管写入与命令。不接受模型提交任意截图路径。`start_visual_review` 可指定父会话自己当前的 debug_session_id 来保留操作状态；归属错误或过期实例拒绝。

材料封存在 `PROMA_HOME/software-quality-materials/<project>/<review>/`：真实 `screen.png` 与 `manifest.json`。记录来源项目/父会话/候选、调试实例/版本/源码、同次 DOM/操作事实、PNG 哈希及 30 分钟有效期；清单本身也有独立哈希。首次授权时为 V 保存新的子会话图片引用，不把父 debug ID 当作子会话图片权限。封存材料、子会话图像任一换字节或清单变化均拒绝。

## V 的输入与图片传输凭据

- 仅提供 `read_quality_review`、`view_quality_image`、`submit_quality_findings`。不提供实现文件、命令、GUI 操作、普通 view_image 或再委派工具。角色工具构造补充实际 childSessionId；旧构造器仍可使用原三个参数。
- V 不继承父会话附件或 C/A 的结论。委派上下文允许宿主按子会话选择材料，C/V 使用自己的确认材料，普通委派保持原有材料行为。
- `read_quality_review` 提供确认业务预期、约束、当前图片绑定及同次 DOM/操作事实；有已确认草图时额外提供最多 64000 字符的 HTML 设计材料，标明界限。该参考不是另一次真实设计截图。
- `view_quality_image` 只能读这个 V 获授权的 PNG，无 path/debug ID 参数。返回实际图像引用，仍标记 `image_attached_not_reviewed`。
- `wrapQuery` 复用原 `requestGuard` 和 `onTransportAttempt`。在实际物理请求出口校验最终序列化的 Anthropic 图像块或 OpenAI data URL：必须含授权 PNG 的实际字节，且不能夹入其他图片；文件名、OCR、DOM 或图片已省略占位均不满足。保持原请求守卫和预算组合，不新增 HTTP 客户端。
- 只有经过请求出口校验、实际传输开始且原 SDK 返回成功结果，宿主才在审阅记录写入图像哈希、请求体哈希与时间。接收图片的协议成功不证明模型理解图片。
- V 提交还须包含非空 `visual_observations`：对应图像哈希、可见区域与具体观察。缺少实际图像传输凭据、候选变化、过期材料或未读确认材料，不能提交，空 finding 也不例外。此约束证明材料确实进入图像传输且模型提交了可见描述，不能证明注意力、诚实性或找错能力。

供应商明确拒绝图片时，保留 `MODEL_IMAGE_INPUT_UNSUPPORTED` 与不含密钥的路由摘要；同一路由停止自动 V 重试，保持未验证。切换当前制作路由后可重新审阅，不能偷偷换渠道或以文字回答替代。没有另加资格探针或借用 B 预算。

## finding 与关闭

V 的 finding 使用 Q1 同一台账，额外绑定 `review_kind=visual` 和视觉材料清单哈希。它只能提出疑点；宿主确认需求依据后，仍用 `check_quality_finding` 实际执行原冻结 GUI/CLI 案例。先在原候选记录失败，A 修复后在新候选以相同规则实测通过，整体验证通过才关闭；修复之后重新 C/V 审阅同一候选。

无明确业务依据的美化意见保留建议或争议，不新增用户需求。截图只代表本次观察状态；操作事实不代表全部用户流程。正式 GUI 业务检查仍由既有验收器独立执行。当前自动采图复用 debug observer 支持的 Electron/浏览器入口；其不支持的入口保留受阻，不声称已完成 V，也不以占位图补齐。
