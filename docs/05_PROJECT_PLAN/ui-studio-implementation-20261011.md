# Bloma 通透画室实施与验证

日期：2026-10-11。实施前 HEAD 为 `88754cb`；验收流程修复已在 `06f4e90`，此前两份 UI 文档属于设计证据。本次实现用户最终明确选择的「通透画室」，只保留白色外观。绿色长期型与紫色快速型作为模式标识，不构成两套主题。

## 最终界面

- 项目、阶段、文档、材料、版本、协作收进窄边栏；草图与当前结果占据主要画布。资料面板覆盖画布边缘，避免进一步压缩草图。
- 白色纸面、轻微暖绿背景光、通透边栏、协调圆角与柔和阴影。设置页重新组织为侧边标签导航；旧消息、选项、状态提示、输入与弹层统一外观，入口使用 Lucide 线稿图标。
- 独立草图视口按 1280×800 的设计尺寸横向适配，页面过长时保留滚动，不按窗口高度把文字缩小。支持原尺寸、适应画布、专注预览；确认后的 `00_UX/confirmed.html` 在制作过程中仍可回看。
- 已确认草图允许鼠标滚动和页面内交互，预览不回写文件。其沙箱仅允许脚本，不授予同源、表单提交或主窗口 Electron 桥接能力。回看草图不等于启动已完成程序。
- 下方讨论带默认呈现当前结果；完整交流独立打开，输入草稿保持。取消将长回复藏在折叠正文里的方案，模型实际输出多少正文，就完整呈现多少。
- 工作记录可查看当前会话最近 200 条原始消息，包括工具与宿主记录；完整 JSONL 保留。这里不是跨会话全量日志查看器。

## 输出与真实按钮

用户界面输出约定在提示词源头要求简短日常中文，默认一至两句话，收口时二至三句话；详细技术证据保留在文件与记录。该约定按用户输出通道应用，不把工作子任务的完整实施内容全局缩短。界面不会通过截断伪造短回复。

消息添加来源标识，新的宿主反馈保留协议角色及原始审计内容，但不进入用户正文或分支锚点。兼容已知旧宿主前缀，显式用户来源和用户提交标识优先。模型正文去除独立阶段协议行，系统欢迎提示不再重复挤占已有结果。

复制贯通渲染层、预加载桥接、主进程与系统剪贴板。等待真实结果后显示「已复制」；失败有可见提示，允许重试，不再静默吞错。

「从此处新开讨论」使用当前项目与原始用户消息锚点创建子会话，切换历史，并把原要求放入可编辑输入框；不会自动提交模型请求。修复旧存储草稿迟到覆盖新分支输入的问题。当前程序和项目阶段保留，文件恢复仍通过版本入口处理，此按钮不承诺回滚文件。
