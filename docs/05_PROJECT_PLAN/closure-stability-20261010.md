# Bloma 细节修复与工程收口

日期：2026-10-10（北京时间）。基线 `sprint2 / 5c84a86`；最终提交以本文件所在 Git 提交为准。

## 本轮范围

检查项目命名、PRD 名称同步、产物导出、提示词配置保存与默认测试入口。仅修改有源码与复现证据的问题，没有扩大生成路线、修改用户现有程序或真实配置，也没有推送远端。

## 已修复

| 问题 | 原行为 | 现在的行为 |
| --- | --- | --- |
| 导出目录名称 | 项目名 `..`/`.` 会使导出落到所选目录外或目录本身；Windows 设备名可能导致导出失败 | 两条导出路径共用目录解析；清理尾点/空格、处理设备名，产物始终写入一个正常子目录。项目显示名与稳定 ID 根目录不变 |
| 导出包中的链接 | 已有目标目录或包内目录 junction/文件 symlink 可使递归复制写到链接目标 | 复制前检查目标路径，拒绝覆盖链接；测试中包外哨兵保持原样 |
| 提示词保存 | 直接覆盖配置；替换失败可能留下不完整内容 | 独占随机临时文件、完整写入后 rename；失败上抛且保留旧配置，不回退直接覆盖。再次保存成功后即时生效 |
| 设置/命名输入错误 | IPC 非文本输入在 `.trim()`/`.replace()` 处报内部异常 | 返回 `VALIDATION_ERROR`，不修改配置或项目 |
| 手动命名同步 | 界面改名只更新项目索引，已有 PRD name/正式标题仍是旧名称 | 项目重命名 IPC 接通 PRD 同步，保留功能项、正文原话、确认时间；只同步名称与正式标题，不改已生成程序 |
| 默认测试发现 | `npm run test:unit` 的路径过滤会把 run-artifacts 中历史测试快照当作当前测试 | 保留 Vitest 默认排除项，统一排除运行证据目录，不再要求每次手工加 CLI 参数 |
