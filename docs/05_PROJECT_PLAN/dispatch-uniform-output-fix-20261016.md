# 全部调用统一 640000 预算修正

用户再次明确所有调用预算应为 640000。此前新 Flash/Pro 登记擅自使用 384000，且交接仍为 1024、收口为 4096；这些设置没有落实用户要求。最初拟将交接改为 32768 仍不符合要求，已撤销该小上限方案。原始配置、花费和中断样本保留，不混入修正后的实验。

## 当前实现

- 主流程、压缩交接、宽限及工具停用后的收口均使用宿主 640000。SDK 实验出口覆盖调用方遗留的小预算；角色守卫也覆盖旧辅助值。运行事件分别保存宿主、调用方旧值与供应商有效上限。
- DS 官方 `/models` 于 2026-10-16 18:46 返回 Flash、Pro 的 `max_output_tokens=393216`，官方 API 参数文档同样规定最大 384K（393216）。宿主保留 640000，只有发送前夹紧到该接口上限；不把 393216 说成实际消耗，也不声称验证了发送 640000 会被拒绝。
- 交接完整消费响应流后，仅接受正常结束的干净文本。`max_tokens` 截断、思考无正文、结构化工具调用或 DSML 等工具协议文本都触发已有确定性交接兜底，保留近期原文和失败上下文，避免把无效文本作为有效摘要。

本地 Proma 上游 `bf3e98ca61dd8365eceaef876c0f7473700878a6` 的 `packages/core/src/providers/anthropic-adapter.ts:310` 说明 effort 模式中 max_tokens 包含思考和正文；借鉴其出口装配与充足预算原则，按用户要求使用 640000，并保留本项目的 agent 协议与实验条件，没有照搬上游 32000。
