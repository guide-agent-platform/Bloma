## 批次 2：独立持续试用

- 需求/外观已确认且有有效启动声明时，可在制作中点击“打开独立试用”。源码/依赖快照、安全扫描和可启动检查通过后才提供试用；明确标注“测试数据、尚未验收”、版本 ID，不能冒充正式交付。
- 用户试用、模型调试和正式验收拥有不同身份、数据目录与 Electron profile；试用浏览器使用独立端口。浏览器程序须读取 PORT/APP_PORT 或显式端口参数；硬编码端口不改写源码，无法独立启动时如实失败。显式共享 user-data-dir 被宿主替换为所属数据目录的 profile。

- 未知/重用 PID 不接管、不终止；旧宿主进程仍活着时要求用户自行关闭。交付启动仍通过 active verified release，试用入口没有发布权限。
