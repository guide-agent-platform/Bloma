## 修复语义

- 对已有命令凭据，重跑前先持久化未知的执行中标记，并回读确认。旧凭据不能失效时不启动脚本。最终写盘失败、进程退出或宿主中断都只能留下未知标记，不能留下可复活的旧 PASS。
- 使用宿主已有累计执行总数生成 `attempt_seq`；活动预算重置不回退该序号。计数回退或旧序号不能覆盖新记录，不用模型自述或墙钟猜先后。
- 通用合并与委派交接按执行序号选择记录，同一次执行的 `EVIDENCE_RECORD_FAILED` 不被 collector 的旧 PASS 或待写标记覆盖。旧格式没有序号仍兼容读取，但不能据此消除写盘失败；更晚一次成功执行可以恢复正常凭据。
- 仅预先失效同一已存在命令的记录；独立逻辑、GUI 凭据及无关诊断不会互相清空。命令完整参数仍参与 key，序号属于宿主项目/子会话。
