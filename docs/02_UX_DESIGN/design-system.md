## 1. 设计目标

本文档定义平台在 Proma 基础上的增量设计系统，用于约束后续前端实现、组件拆分和交互测试。

本设计系统不重建 Proma 原有能力，只定义本平台为“软件生成工作区”新增或改造的 UI 规则：

- 两道门选择页
- 快消型/长期迭代型工作区
- 预览区与沙箱控制
- 点选纠错弹窗
- 时间轴与快照卡片
- 模式升级确认框
- 等待、超时、异常反馈状态
- 文档面板

---

## 2. 设计原则

| 原则 | 说明 | 落地要求 |
|---|---|---|
| 预览优先 | P0 用户通过“看”确认方向 | 预览区占主视觉宽度，文档面板默认不抢占注意力 |
| 对话不压迫 | 用户始终面对一个向导 Agent | 对话区保持稳定，不显示内部角色名称 |
| 状态可见 | 等待、修复、回滚、裁判判定都要有明确反馈 | 超过 5 秒必须显示进度提示 |
| 风险可退 | 高风险修改、升级、回滚都必须有快照提示 | 所有不可逆感知操作前提供确认或快照说明 |
| 术语克制 | 面向用户界面不暴露技术术语 | PlantUML、GWT、OWASP 等只出现在文档面板或研究/工程视图 |
| 低装饰密度 | 产品是工作工具，不做营销页 | 不使用大面积装饰插画、渐变球、复杂背景 |

## 3. Design Tokens

### 3.1 色彩

| Token | 值 | 用途 |
|---|---:|---|
| `--color-bg` | `#f5f6f3` | 应用背景 |
| `--color-surface` | `#ffffff` | 面板、弹窗、卡片 |
| `--color-surface-muted` | `#fbfbfa` | 对话区、轻量辅助区域 |
| `--color-text` | `#202421` | 主文本 |
| `--color-text-muted` | `#66706a` | 次级文本、状态说明 |
| `--color-border` | `#d8ded8` | 分割线、输入框、卡片边框 |
| `--color-quick` | `#087f72` | 快消型主色、主要行动按钮 |
| `--color-quick-soft` | `#e0f3ee` | 快消型标签和轻提示背景 |
| `--color-longterm` | `#6b5b95` | 长期迭代型主色 |
| `--color-longterm-soft` | `#ebe7f6` | 长期迭代型标签和轻提示背景 |
| `--color-warning` | `#b7791f` | 超时、需注意状态 |
| `--color-danger` | `#c2412d` | 高风险、安全问题、失败状态 |
| `--color-focus` | `#2f80ed` | 键盘焦点轮廓 |

### 3.2 字体

| Token | 值 | 用途 |
|---|---|---|
| `--font-family-base` | `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` | 全平台默认字体 |
| `--font-size-xs` | `12px` | 标签、时间轴摘要 |
| `--font-size-sm` | `13px` | 状态文本、辅助说明 |
| `--font-size-md` | `14px` | 消息、表单、正文 |
| `--font-size-lg` | `18px` | 面板标题 |
| `--font-size-xl` | `22px` | 弹窗标题 |
| `--font-size-2xl` | `28px` | 两道门卡片标题 |

规则：

- 不使用随视口缩放的字体。
- 字距保持默认，不使用负字距。
- 面板内标题不使用 hero 级大字。
- 中文正文行高建议 `1.55` 到 `1.75`。

### 3.3 间距与尺寸

| Token | 值 | 用途 |
|---|---:|---|
| `--space-1` | `4px` | 标签内部间距 |
| `--space-2` | `8px` | 小组件间距 |
| `--space-3` | `12px` | 消息、按钮组间距 |
| `--space-4` | `16px` | 面板内基础间距 |
| `--space-5` | `20px` | 卡片组间距 |
| `--space-6` | `24px` | 页面主内容内边距 |
| `--header-height` | `52px` | 工作区顶栏 |
| `--timeline-collapsed-height` | `58px` | 时间轴折叠高度 |
| `--timeline-expanded-height` | `230px` | 时间轴展开高度 |
| `--radius-sm` | `6px` | 按钮、输入框、标签 |
| `--radius-md` | `8px` | 卡片、弹窗、预览容器 |

规则：

- 卡片、弹窗、工具面板圆角不超过 `8px`。
- 工作区结构使用稳定网格尺寸，避免消息、标签、按钮变化导致布局跳动。
- 时间轴折叠态必须保持低高度，不挤压预览区。

### 3.4 阴影

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-sm` | `0 1px 0 rgba(0,0,0,.04)` | 静态卡片 |
| `--shadow-md` | `0 8px 24px rgba(30,38,34,.08)` | 预览容器 |
| `--shadow-lg` | `0 18px 52px rgba(0,0,0,.22)` | 模态弹窗 |

阴影只用于表达层级：悬浮卡片、弹窗、Toast。页面 section 不使用悬浮卡片式阴影。

## 4. 布局规范

### 4.1 两道门选择页

| 区域 | 规则 |
|---|---|
| 顶栏 | 保留品牌和历史项目入口，高度 56px |
| 主体 | 居中容器，最大宽度 980px |
| 卡片 | 桌面双列，移动端单列 |
| 快速尝鲜卡片 | 使用快消型主色 |
| 精细打磨卡片 | 使用长期迭代型主色 |
| 选择后 | 进入对应工作区，不提供运行时返回两道门 |

### 4.2 快消型工作区

| 区域 | 桌面规则 | 移动端规则 |
|---|---|---|
| 顶栏 | 项目名 + 模式标签 + 阶段指示器 + 所有项目入口 | 保持单行，项目名可截断 |
| 对话区 | 左侧约 35% 宽 | 上方约 44% 高 |
| 预览区 | 右侧约 65% 宽 | 下方约 56% 高 |
| 时间轴 | 底部 58px 折叠条 | 底部可横向滚动 |

### 4.3 长期迭代型工作区

| 区域 | 展开规则 |
|---|---|
| 对话区 | 约 30% 宽 |
| 文档面板 | 展开态约 180px 到 15% 宽 |
| 预览区 | 剩余主宽度，最低 50% |
| 文档面板折叠 | 折叠后快消型和长期迭代型布局接近 |
| 小屏 | 宽度 < 900px 时文档面板自动折叠 |

### 4.4 预览区

预览区是主要工作面，应始终优先获得空间。

| 元素 | 规则 |
|---|---|
| 沙箱容器 | 白底、1px 边框、8px 圆角 |
| 控制栏 | 显示安全预览环境、刷新、全屏 |
| iframe/WebView | 禁止顶部导航，禁止原生弹窗干扰 |
| 空状态 | 不显示“暂无数据”等冷冰冰文案，使用自然语言引导 |
| 错误状态 | 不显示堆栈、HTTP 状态码、函数名 |

## 5. 组件规范

### 5.1 模式卡片

| 属性 | 规则 |
|---|---|
| 类型 | `ModeCard` |
| 状态 | default、hover、focus、selected、disabled |
| 内容 | 图标、标题、一句话说明、辅助提示 |
| 交互 | 点击整卡进入对应模式 |
| 可访问性 | `button` 语义，支持 Enter/Space |

### 5.2 消息气泡

| 类型 | 规则 |
|---|---|
| 向导消息 | 左对齐，浅灰背景 |
| 用户消息 | 右对齐，模式主色背景 |
| 系统状态消息 | 使用轻提示卡片，不冒充用户或向导 |
| 技术消息 | 不出现在普通用户对话区 |

### 5.3 卡片选项

卡片选项用于替代复杂文本输入。

| 规则 | 说明 |
|---|---|
| 数量 | 单轮建议 2 到 3 个，最多不超过 4 个 |
| 文案 | 使用用户语言，如“日常开销”“你帮我决定” |
| 布局 | 可换行 chip 或小卡片 |
| 选择后 | 选项回写到对话上下文 |

### 5.4 点选纠错弹窗

| 属性 | 规则 |
|---|---|
| 触发 | 用户点击预览区元素 |
| 定位 | 优先贴近被选元素，小屏固定底部 |
| 标题 | “这里有什么问题？” |
| 操作 | “提交”“你猜” |
| 上下文 | 后台记录点击位置、DOM 信息、截图坐标 |
| 关闭 | Esc 或点击“你猜”，表示无文字说明的不满意 |

### 5.5 时间轴快照卡片

| 元素 | 规则 |
|---|---|
| 缩略图 | 展示预览截图，不用纯文本替代 |
| 标题 | 如“验证草图 v1”“MVP v1”“升级前快照” |
| 摘要 | 一句自然语言描述 |
| 操作 | “回到这里”或“当前版本” |
| 当前状态 | 使用边框高亮，不改变卡片尺寸 |

### 5.6 回滚确认弹窗

| 属性 | 规则 |
|---|---|
| 标题 | “回到‘某版本’？” |
| 说明 | 明确后续版本仍保留 |
| 主操作 | “确认回到这里” |
| 次操作 | “取消” |
| 快照 | 回滚本身不删除任何快照 |

### 5.7 模式升级确认框

| 属性 | 规则 |
|---|---|
| 触发 | 快消型项目达到可用或完成状态 |
| 主文案 | 说明升级为长期维护项目 |
| 收益点 | 补全文档、Sprint 计划、升级前快照 |
| 主操作 | “确认升级” |
| 次操作 | “暂不升级” |
| 取消后 | 入口保留，不打断当前项目 |

### 5.8 文档面板

| 属性 | 规则 |
|---|---|
| 可见范围 | 仅长期迭代型默认可用 |
| 默认状态 | 折叠或窄面板 |
| 内容 | PRD、用户故事、PlantUML、GWT Feature、测试报告 |
| 用户视图 | 默认显示自然语言概览 |
| 工程视图 | 可在后续版本提供源码/机读内容 |

### 5.9 等待反馈卡片

等待反馈应作为对话区内的系统状态卡片，不应覆盖整个工作区。

| 场景 | 文案要求 |
|---|---|
| >5 秒 | 说明正在做什么 |
| >10 秒 | 增加安全感说明 |
| >120 秒 | 告知比预期更长，允许查看已生成部分或继续等待 |
| 自动修复中 | 告知正在尝试修复，不显示技术错误 |
| 熔断回滚 | 告知已回到上一个正常版本 |

## 6. 状态规范

### 6.1 项目阶段指示器

| 阶段 | 用户可见文案 |
|---|---|
| `mode_selected` | 已选择模式 |
| `understanding` | 正在理解需求 |
| `clarifying` | 等待你确认几个问题 |
| `generating_sketch` | 正在生成草图 |
| `sketch_ready` | 草图已生成 |
| `generating_mvp` | 正在构建 MVP |
| `testing` | 正在检查能不能正常使用 |
| `repairing` | 正在尝试修复 |
| `ready` | 可以试用了 |
| `completed` | 已完成 |

### 6.2 操作状态

| 状态 | 视觉 |
|---|---|
| 默认 | 白底、灰边 |
| Hover | 轻微上移或边框加深 |
| Focus | `--color-focus` 3px 轮廓 |
| Active | 模式主色边框或背景 |
| Disabled | 降低不透明度，不可点击 |
| Error | 危险色边框，配自然语言说明 |
| Loading | spinner + 状态文案 |

## 7. 响应式规则

| 断点 | 规则 |
|---|---|
| `< 900px` | 长期迭代型文档面板自动折叠 |
| `< 760px` | 工作区上下堆叠，对话区在上，预览区在下 |
| `< 720px` | 两道门卡片单列 |
| `< 520px` | 弹窗操作按钮纵向排列 |

移动端优先保证：

- 文案不溢出按钮或卡片。
- 弹窗不遮挡关键输入区。
- 时间轴允许横向滚动。
- 预览区可以全屏查看。

## 8. 可访问性

| 项目 | 要求 |
|---|---|
| 键盘导航 | Tab 顺序：顶栏 → 对话区 → 预览控制 → 时间轴 → 弹窗 |
| 焦点样式 | 所有按钮、卡片、输入框必须有可见焦点 |
| 语义 | 可点击卡片使用 `button` 或正确 ARIA |
| 弹窗 | 使用 `role="dialog"` 和 `aria-modal="true"` |
| Esc | 关闭弹窗或退出全屏 |
| 对比度 | 主文本和背景满足常规阅读对比 |

## 9. `data-ai-id` 命名规范

所有关键 UI 节点必须有稳定 `data-ai-id`，用于测试、Agent 操作和设计审查。

命名规则：

- 使用 kebab-case。
- 名称描述功能而非视觉位置。
- 不使用动态编号作为唯一含义。

示例：

| 元素 | 推荐 ID |
|---|---|
| 两道门页面 | `mode-selection-page` |
| 快消型卡片 | `mode-card-quick` |
| 长期迭代型卡片 | `mode-card-longterm` |
| 工作区顶栏 | `workspace-header` |
| 对话区 | `chat-panel` |
| 预览区 | `preview-panel` |
| 文档面板 | `document-panel` |
| 纠错弹窗 | `point-correction-popover` |
| 时间轴展开面板 | `timeline-expanded-panel` |
| 回滚确认弹窗 | `rollback-confirm-modal` |
| 模式升级弹窗 | `mode-upgrade-modal` |
