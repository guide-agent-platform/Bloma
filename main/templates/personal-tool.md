# 模板：个人小工具（PRD 12.3 宽松级）

适用：单页工具、计算器、生成器、计时器、待办清单等单人使用的小工具（含无 UI 脚本类诉求的网页化交付）。

## 硬约束等级：宽松（PRD 12.4 宽松列）

- PRD 必须包含：项目名称、核心功能（quick 五必填章即可开工）
- API Spec：自动推断即可（interface_spec 可空数组）
- 安全扫描：OWASP Top 5（XSS 注入必测）
- 测试覆盖率：核心功能（P0 必测；边界至少 1 条）

## PRD 章节必填子集

- quick：产品定位 / 功能清单 / 页面清单(≤3) / 行为断言(EARS) / GWT 场景 / 范围外
- longterm：+ 目标用户 / 术语表 / API Spec

## 依赖白名单（loop 引白名单外包 → 工具层拦截）

- 允许：原生 HTML / CSS / JavaScript（ES2022），单文件产物可接受
- 允许：localStorage
- 禁止：外部 CDN / npm 包 / 后端框架 / 数据库
- 禁止：账号体系 / 多用户 / 云同步（小工具默认单机单人）

## tech_skeleton（目录约定 / 构建配置 / 入口约定）

- index.html 为唯一入口（单屏为主；超出首屏的清单可滚动，不设多级导航）
- 逻辑可内联 <script> 或拆 src/app.js（与 hasInteractiveEntry 判据兼容即可）
- 控件即功能：无设置页、无帮助页；一切配置就地呈现

## 视觉规范（草图外观基线）

- 布局：单栏或紧凑双栏，一屏聚焦一个主任务；不设 hero 横幅、营销区块、装饰性插画
- 配色：中性底色 + 一个强调色（按产品气质选：专注类蓝绿、记录类暖棕、效率类深灰），不堆渐变
- 密度：信息密度适中，控件间距 ≥8px；列表项一屏可见 5~8 条
- 文案：界面文案全中文、口语化；示例数据贴合产品语义（如记账用「午餐 25 元」），不用占位乱数

## 测试策略

- 安全扫描等级 = OWASP Top 5（XSS 注入用例必测）
- 测试覆盖率 = 核心功能（P0 happy path 全覆盖 + 边界≥1）
- GWT 必测类别：happy path / 边界（空输入）/ 异常（非法值）

## 同类型脱敏样例（few-shot，≤500 token，注入 PRD 生成）

需求：做个番茄钟，能开始、暂停、重置，专注完计数加一。
定位：面向个人学习工作者的单屏专注计时工具。
PRD 全文（document）：定位/用户故事/功能详述/页面约定/范围外/假设八节长文本，功能详述验收要点与 acceptance 逐字同源。
功能与断言（EARS 形态）：
- F-001 计时控制：WHEN 点击开始按钮 → 计时启动；WHEN 点击暂停按钮 → 计时停止；WHEN 点击重置按钮 → 显示回到 25:00
- F-002 完成计数：WHEN 计时走到 00:00 → 今日完成数加一
范围外：任务清单、统计图表、提示音设置。
