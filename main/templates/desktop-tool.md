# 模板：桌面工具（PRD 12.3 标准级）

适用：效率工具、本地应用（当前阶段以本地单页应用形态交付，UI 按桌面工具惯例：单窗体、无站点导航、键盘可达）。

## 硬约束等级：标准（PRD 12.4 标准列）

- PRD 必须包含：项目名称、核心功能、目标用户、验收标准
- API Spec：自动推断即可（本地工具无对外端点；interface_spec 可空数组）
- 安全扫描：OWASP Top 10（本地文件读取类工具重点测路径注入与敏感目录访问）
- 测试覆盖率：全部功能 + 边界

## PRD 章节必填子集

- quick：产品定位 / 功能清单 / 页面清单(≤3) / 行为断言(EARS) / GWT 场景 / 范围外
- longterm：+ 目标用户 / 术语表 / API Spec

## 依赖白名单（loop 引白名单外包 → 工具层拦截）

- 允许：原生 HTML / CSS / JavaScript（ES2022），无构建链静态产物
- 允许：localStorage（本地持久化首选）
- 禁止：外部 CDN / npm 包 / Node API / Electron API（沙箱静态阶段不可达）
- 禁止：自动下载安装包 / 注册表 / 系统设置写入类表述

## tech_skeleton（目录约定 / 构建配置 / 入口约定）

- index.html 为唯一入口（桌面单窗体：无顶栏导航、无页脚链接，控件即主体）
- src/app.js 为逻辑入口；键盘事件（keydown）为一级交互（快捷键惯例）
- src/style.css 可选拆分；工具型布局（表单/列表/统计区紧凑排布）
- 桌面语义约束：禁用浏览器惯用元素（外链新窗口、面包屑、分页器）

## 测试策略

- 安全扫描等级 = OWASP Top 10（文件路径类输入必测路径穿越）
- 测试覆盖率 = 全部功能 + 边界（键盘触发路径与鼠标点击路径等价覆盖）
- GWT 必测类别：happy path / 边界（空输入、超长输入）/ 异常（非法文件、快捷键冲突态）

## 同类型脱敏样例（few-shot，≤500 token，注入 PRD 生成）

需求：做个批量重命名工具，按规则改文件名，改之前能预览。
定位：面向内容创作者的本地批量重命名工具，规则一次配置、预览确认后批量执行。
PRD 全文（document）：定位/用户故事/功能详述/页面约定/约束/范围外/假设八节长文本，功能详述验收要点与 acceptance 逐字同源。
功能与断言（EARS 形态）：
- F-001 配置规则：WHEN 输入查找词与替换词 → 预览列表实时刷新
- F-002 批量执行：WHEN 点击「应用重命名」按钮 → 预览列表全部标记为已完成；IF 规则为空 → 按钮禁用
范围外：云盘文件、正则高级语法。
