# 模板：游戏 / 互动媒体（PRD 12.3 标准级）

适用：小游戏、网页游戏、街机复刻、闯关/跑酷/塔防等互动媒体项目。产物形态同为 web 全栈（index.html + src/app.js），但验证策略与普通网页不同——测的是玩法（状态机/碰撞/胜负），不是表单边界。

## 硬约束等级：标准（PRD 12.4 标准列）

- PRD 必须包含：项目名称、核心玩法、目标用户、验收标准
- 安全扫描：OWASP Top 10（XSS 注入 / 敏感数据暴露必测）
- 测试覆盖率：全部功能 + 玩法边界

## PRD 章节必填子集

- quick：产品定位 / 功能清单 / 页面清单(≤3) / 行为断言(EARS) / GWT 场景 / 范围外
- longterm：+ 目标用户 / 术语表 / API Spec

## 依赖白名单（loop 引白名单外包 → 工具层拦截）

- 允许：原生 HTML / CSS / JavaScript（ES2022），无构建链静态产物
- 允许：canvas 2D / requestAnimationFrame / 键盘·鼠标·触摸事件 / 游戏循环
- 允许：localStorage（本地最高分/存档）
- 注意：fetch 在预览沙箱不可用（CSP 禁网）——数据一律用内联对象字面量/内嵌 script 表达，不要发起任何网络请求（含同源）
- 禁止：外部 CDN / npm 包 / 后端框架 / 数据库（沙箱阶段）
- 禁止：内联第三方统计/广告脚本

## tech_skeleton（目录约定 / 构建配置 / 入口约定）

- index.html 为唯一入口（<style> 内联或 link 引 src/style.css，</html> 收尾——isHtmlDocument 判据）
- src/app.js 为逻辑入口（含全部交互逻辑；hasInteractiveEntry 判据：addEventListener/onclick 家族）
- src/style.css 可选拆分
- 游戏特有：canvas 画布 / 游戏循环（requestAnimationFrame）/ 输入状态（键盘按键码 / 鼠标坐标）

## 常见模式范式（实现要点提示，非必选）

- 游戏循环：requestAnimationFrame 驱动；update（状态推进）+ render（绘制）分离；暂停/恢复切换循环。
- 状态机：把「主菜单 / 进行中 / 暂停 / 结束 / 胜利」建模为显式状态，状态切换只经单一入口，禁止散落的布尔标志拼状态。
- 碰撞检测：矩形 AABB 相交为基线；检测与响应分离（检测只判相交、响应决定反弹/扣血/得分）。
- 胜负判定：胜利/失败条件显式、可观察（分数达标 / 生命归零 / 到达终点），结局态清空输入防误触。
- 计分与生命周期：得分/生命/关卡变量集中管理，归零与重置走同一入口，避免状态残留。
- 键盘/触摸输入：keydown 记录按键态、keyup 清除；方向键与 WASD 双通道；触摸端给虚拟按钮兜底。

## 视觉规范（草图外观基线）

- 布局：画布为主（居中）；HUD（分数/生命/关卡）固定于顶部或角落，不与画布重叠
- 状态：主菜单 / 暂停菜单 / 结束结算屏三种覆盖层都要有明确的返回入口
- 配色：按题材选色系（像素复古/霓虹/卡通），主色一个、辅助色 ≤2
- 密度：画面元素轮廓清晰，可点击区域不小于手指/鼠标命中阈值
- 文案：界面文案全中文；胜负结算文案明确（「你赢了」「游戏结束」+ 分数）

## 测试策略

- 安全扫描等级 = OWASP Top 10（XSS：<script>alert(1)</script> 注入用例必测；敏感数据不暴露）
- 测试覆盖率 = 全部功能 + 玩法边界（每功能项：正常路径 + 状态机/碰撞/胜负边界各≥1）
- GWT 必测类别：happy path / 状态机（暂停·结束·胜利态切换）/ 碰撞（碰撞后得分或扣血）/ 胜负边界（生命归零/分数达标）

## 同类型脱敏样例（few-shot，≤500 token，注入 PRD 生成）

需求：做一个贪吃蛇小游戏，方向键控制，吃到食物变长，撞墙或撞自己结束。
定位：面向休闲玩家的网页贪吃蛇，方向键控制蛇移动，吃食物得分变长，撞墙或撞自身游戏结束。
PRD 全文（document）：定位/用户故事/功能详述/页面约定/约束/范围外/假设八节长文本，功能详述验收要点与 acceptance 逐字同源。
功能与断言（EARS 形态）：
- F-001 方向控制：WHEN 按右方向键 → 蛇头向右移动一格；WHEN 按上方向键 → 蛇头向上移动一格
- F-002 吃食物：WHEN 蛇头碰到食物 → 食物重新生成且蛇身长度 +1、得分 +1
- F-003 碰撞结束：WHEN 蛇头撞墙或撞自身 → 游戏进入结束态并显示得分
- F-004 暂停：WHEN 点击暂停 → 游戏循环停止并显示继续按钮；WHEN 点击继续 → 游戏循环恢复
范围外：联机对战、道具系统、多关卡。
